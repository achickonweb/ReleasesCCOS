# CivCivOS 🐣

A Windows XP simulator you can play: a whole fake desktop with apps, games, a fake internet, a coin economy,
achievements, mysteries and an optional "don't download that" story.

## Download

**[Download the latest CivCivOS.exe](https://github.com/achickonweb/ReleasesCCOS/releases/latest/download/CivCivOS.exe)**
(Windows 10/11, one file, no install needed), or pick a version on the [Releases](https://github.com/achickonweb/ReleasesCCOS/releases) page.

- The exe isn't signed with a paid certificate, so Windows may show "Windows protected your PC".
  Click **More info → Run anyway**.
- It runs full screen. Hidden exit: `Ctrl + Alt + Shift + F12 + F11`, or Start → Turn Off Computer.
- Saves are kept in `%LOCALAPPDATA%\CivCivOS` and survive updates.

## Updates

CivCivOS checks this page when it starts and offers new versions by itself
(Update now / Remind me later / Skip this version). Every update is signed by the developer, and the game
refuses anything that isn't. You can turn the check off in the game's Control Panel → Automatic Updates.

This repository only hosts the built game; the source code isn't published.
